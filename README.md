# Evolving Lives · Digital Safety & Family Wellness (V1 prototype)

Vite + React + Tailwind. Single-page prototype of the Understand / Navigate / Engage platform.

## Deploy
1. Push this folder to a new GitHub repo (WynwoodDreams/evolving-lives).
2. Vercel > Add New Project > Import the repo. Framework auto-detects as Vite. No env vars.

## Local
    npm install
    npm run dev
